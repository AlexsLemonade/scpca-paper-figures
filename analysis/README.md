This directory contains code or analyses performed comparing bulk and pseudobulk expression data.


## Included in manuscript

* `pseudobulk-bulk-prediction` performs the overrepresentation analysis as presented in the manuscript

## Not included in manuscript

* `bulk-deconvolution` explores performing deconvolution on bulk and pseudobulk data using methods [`quanTIseq`](https://doi.org/10.1186/s13073-019-0638-6) and [`EPIC`](https://doi.org/10.1007/978-1-0716-0327-7_17)
* `estimate` explores the use of the [`ESTIMATE`](https://doi.org/10.1038/ncomms3612) approach to quantify immune and stromal contributions to samples
