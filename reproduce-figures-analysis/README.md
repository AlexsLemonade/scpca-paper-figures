This directory contains information to facilitate reproducing manuscript figures, tables, and analyses.

* `obtain-prepare-data.md` contains instructions for how to obtain and prepare additional data needed to reproduce figures and analyses
* `prepare-metadata-files.R` is a script which can be used to generate metadata files needed to reproduce figures, tables, and analyses, as described in `obtain-prepare-data.md`.
* `bulk-analysis-samples.tsv` contains a list of ScPCA sample ids which were used in bulk RNAseq analysis.
This list can be used when preparing files to reproduce the analysis, as described in `obtain-prepare-data.md`.
